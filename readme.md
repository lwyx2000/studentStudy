# 全小学阶段儿童粗心矫正系统｜全域 8 页面 UI/UX 布局设计规范

---

### 🗺️ 系统全局页面地图（Sitemap）
```
├── 1. 注册与执行功能基线评估页 (Onboarding & Assessment)
├── 2. 亲子协同主仪表盘 (Parent/Child Dashboard) - [核心枢纽，分年级变体]
├── 3. 每日微习惯打卡与物理生成器 (Habit & Printable Center)
├── 4. 藏宝库（题库）(Treasure Bank / Question Bank)
├── 5. 物品流失追踪与收纳实验室 (Item Tracker & Organization Lab)
├── 6. 6年长期成长档案与预警中心 (Growth Archive & Smart Alert)
```

### 1. 注册与执行功能基线评估页 (Onboarding & Assessment)

*   **设计目标：** 收集儿童物理年级与实际执行功能水平，确立干预基线，缓解家长首入焦虑。
*   **视觉风格：** 温暖、柔和、卡片式流式引导，避免医疗评估的冰冷感。

#### 📐 页面布局 (Layout Grid)
*   **左侧 (40%)：** "小树成长"插画，随着输入信息，小树苗展示不同的初始形态（视觉隐喻）。
*   **右侧 (60%)：** 三步走交互卡片。

#### 🧩 核心组件与交互 (Components & Interaction)
1.  **双轨信息输入组件：**
    *   **物理年级选择器：** 1-6年级滑动选择钮。
    *   **执行功能评估表（CBT量表微缩版）：** 5道滑动条滑块（Slider），让家长评估孩子的"专注持久度"、"物品整洁度"、"情绪克制力"等。
2.  **基线生成动态视效：**
    *   点击"生成档案"，页面呈淡入淡出动画，显示："Leo 的物理年级：3年级，当前执行功能推荐起点：Level 2 难度。"
3.  **【UX 心理学埋点】不确定感消除：** 明确提示家长："此结果仅用于个性化定制每日任务密度，不代表智力水平，后续随打卡数据自动动态修正。"

### 2. 亲子协同主仪表盘 (Parent/Child Dashboard) - 核心页

*   **设计目标：** 亲子日常高频交互的入口，展示今日核心任务与即时反馈。
*   **【关键设计】年级自适应视觉变体 (Responsive UI by Grade)：**

#### 📐 页面布局 - 低年级版 (1-2年级：极简/视觉卡片式)
```
+-------------------------------------------------------------+
|  [Leo的小树苗(Lvl 1)]           [阳光值: 120]  [我的勋章馆] |
+-------------------------------------------------------------+
|                                                             |
|   +-----------------------------------------------------+   |
|   |                  ★ 今日指读任务 ★                  |   |
|   |         [动笔前用手指着读题并圈出大题号]             |   |
|   |                     [ 确认完成 ]                    |   |
|   +-----------------------------------------------------+   |
|                                                             |
|   +--------------------------+  +--------------------------+ |
|   |     🎒 整理书包(3分区)    |  |       🧠 舒尔特方格      | |
|   |         [ 去完成 ]       |  |         [ 开始玩 ]       | |
|   +--------------------------+  +--------------------------+ |
|                                                             |
|   [一键打印纸质打卡单 (PDF)]                     [家长登录入口] |
+-------------------------------------------------------------+
```
*   **低年级 UX 逻辑：**
    *   **零文字干扰：** 大卡片设计，搭配可爱的手绘风图标（如一只手指着书本表示"指读"）。
    *   **单任务聚焦：** 屏幕最显眼位置只放"一个本周聚焦的主线习惯卡片"，做完才能解锁下一个。
    *   **无复杂数据：** 只看得到成长树、阳光值和勋章。

#### 📐 页面布局 - 高年级版 (5-6年级：高信息密度/数据仪表盘)
*   **上方左侧：** "时间管理"番茄钟入口与今日时间轴（Time Block）。
*   **上方右侧：** 今日任务优先级清单（四象限看板：紧急且重要、重要不紧急等）。
*   **下方左侧：** 错题复习提醒卡（显示今日待复习错题数）。
*   **下方右侧：** 空间收纳状态与试卷归档进度。
*   **高年级 UX 逻辑：** 强化自主掌控感，采用冷色调（深灰蓝、白），给孩子一种"我在像大人一样管理自己生活"的成就感。

### 3. 每日微习惯打卡与物理生成器 (Habit & Printable Center)

*   **设计目标：** 提供任务的详细操作指引，并通过"物理打印"功能将干预拉回物理世界。

#### 📐 页面布局 (Layout Grid)
*   **顶部：** 本周习惯养成进度条（进度1/3、2/3...）。
*   **中部：** 习惯标准操作程序（SOP）滑块，配合高清 GIF/小视频，直观展示"怎么算规范的圈画题号"。
*   **底部：** 实体打印控制面板。

#### 🧩 核心组件与交互 (Components & Interaction)
1.  **"打印工具箱"卡片组件：**
    *   展示 A4 尺寸的打卡单预览图。
    *   **一键发送打印交互：** 点击"发送打印"，支持 AirPrint/局域网打印。
    *   **拍照回传核销组件：** 家长周末只需将纸质打卡单平放，用手机拍照，AI 自动扫描手写勾选痕迹，生成数据报告。
2.  **家长打卡红线提示（非侵入式弹窗）：**
    *   家长点击"今日自查"时，页面弹出温和提示："今天您是否克制了对孩子的催促和代劳？勾选'是'，您的教育边界感又前进了一步。"

### 4. 藏宝库（题库）(Treasure Bank / Question Bank)

*   **设计目标：** 手工录入或批量导入错题，按科目/分类查看错题列表；AI智能选题打印复习；图表展示薄弱环节；支持标准JSON格式导入外部题库。

#### 📐 交互流程与界面布局 (Interaction Flow)
```
┌─ Tab 导航栏 ──────────────────────────────────────────────┐
│ [📋 错题列表] [✏️ 录入错题] [🖨️ 选题打印] [📊 薄弱分析] [📥 导入/导出] │
└──────────────────────────────────────────────────────────┘

📋 错题列表：按科目/解决状态筛选，支持勾选 → 打印
✏️ 录入错题：手工填写科目、题型、题目正文、答案、知识点、是否粗心 + 12类分类
🖨️ 选题打印：手工选择 / AI智能选择 → 预览 → 打印(含可选答案)
📊 薄弱分析：按科目柱状图 + 按粗心分类柱状图 + 高频知识点Top10 + 难度分布
📥 导入/导出：拖拽上传JSON文件(符合v1.0格式) → 校验 → 导入结果反馈；一键导出
```

#### 🧩 核心组件与交互 (Components & Interaction)
1.  **手工录入错题表单：**
    *   科目(数学/语文/英语/科学/其他)、题型(选择/填空/计算/作文/其他)、年级(1-6)、难度(1-5★)。
    *   题目正文(必填)、参考答案(选填)、教材章节、知识点标签(逗号分隔)。
    *   是否粗心型错误 → 是：12类粗心分类九宫格选择；否：直接归档。
2.  **错题列表：**
    *   支持按科目、已解决/未解决状态筛选。每条显示科目标签、题型、难度、粗心分类、知识点标签。
    *   勾选框用于选题打印。操作：标记已解决、删除。
3.  **选题打印：**
    *   手工选择模式：在列表中勾选，或全选未解决题目。
    *   AI智能选择模式：优先选择复习次数少、难度高、且未解决的题目（上限10题）。
    *   打印预览 + 可选附带答案 → 弹出打印窗口。
4.  **薄弱环节图表：**
    *   按科目分布柱状图、按粗心分类柱状图、高频知识点Top10柱状图、难度分布竖向柱状图。
5.  **外部题库导入：**
    *   仅支持 `.json` 格式，须符合 v1.0 标准格式规范。
    *   拖拽上传或点击选择文件。校验版本号、必填字段、枚举值。
    *   导入结果反馈：成功/部分成功(附失败原因)/失败。
    *   支持一键导出当前题库为标准JSON格式。
6.  **导入格式规范 (v1.0)：**
    ```json
    {
      "version": "1.0",
      "exportedAt": "2026-06-05T10:00:00Z",
      "schoolInfo": { "name": "XX小学", "grade": 3 },
      "questions": [
        {
          "subject": "math",
          "type": "calculation",
          "content": "计算：3.25 × 4 =",
          "answer": "13",
          "grade": 3,
          "chapter": "第3单元",
          "knowledgePoints": ["小数乘法"],
          "difficulty": 2,
          "tags": ["易错"]
        }
      ]
    }
    ```
    *   **必填：** version("1.0")、questions[].subject、questions[].type、questions[].content
    *   **选填：** answer、grade(缺省取schoolInfo.grade或3)、chapter、knowledgePoints、difficulty(缺省3)、tags

### 5. 物品流失追踪与收纳实验室 (Item Tracker & Organization Lab)

*   **设计目标：** 记录物品丢失，形成账单反馈，激发责任感；提供收纳指导。

#### 📐 页面布局 (Layout Grid)
*   **上半部分（物品管理舱）：** 虚拟书包透视图。未丢物品显示为绿色，丢失物品显示为红色"丢失"标签。
*   **下半部分（流失分析）：**
    *   **左：** 丢失物品高频地点雷达图（学校、公交、家里）。
    *   **右：** 丢失代价"累计账单折线图"（直观展示丢橡皮、水杯累计损失的金额）。

#### 🧩 核心组件与交互 (Components & Interaction)
1.  **高频流失警报器 (Visual Alert Widget)：**
    *   若某物品（如橡皮）30天内丢失满3次，该物品卡片呈呼吸红光闪烁，并显示一个"急救卡片"按钮，点击弹出："建议立刻在橡皮上贴上醒目的荧光色姓名贴，并规定橡皮用完必须放回笔盒右侧。"
2.  **"收纳前后对比"照片墙：**
    *   左右分栏组件（Before / After）。孩子拍下凌乱的书桌和整理后的书桌，用滑块左右拖动查看对比，点击"上传，赢取阳光值"。

### 6. 6年长期成长档案与预警中心 (Growth Archive & Smart Alert)

*   **设计目标：** 给家长提供客观、无贬低的数据反馈，追踪习惯变化趋势。

#### 📐 页面布局 (Layout Grid)
*   **左侧：** 长期成长折线图（漏题率、丢东西频次、任务完成率），可按年/学期进行时间跨度筛选。
*   **右侧：** "同龄常模对比"蜘蛛网图（包含专注、整洁、元认知、情绪四个维度）。
*   **底部：** 智能诊断预警信息流。

#### 🧩 核心组件与交互 (Components & Interaction)
1.  **智能预警卡片 (Diagnostic Alert Card)：**
    *   *非焦虑设计：* 标题不能出现"警报/糟糕"字样，而是使用："💡 阶段性发展发现"。
    *   *内容示例：* "近7天 Leo 的'看错符号错误'环比上升了25%，这通常由于近期作业量增大导致的视觉疲劳引起。建议：将晚上写作业的中间休息频率提高至'写20分钟休息5分钟'，并确保台灯亮度调高一档。"
2.  **PDF 成长报告一键分享/打印：**
    *   设计精美、排版大气的"执行功能综合发展报告"，可一键生成 PDF 分享给学校老师或打印留存。

### 7. [5-6年级专属] 时间与学习自治舱 (Time & Task Cabin)

*   **设计目标：** 满足高年级孩子自我管理、规划考前复习的需求，培养其元认知。
*   **视觉风格：** 更加沉浸、偏暗色调或中性冷静色调，减少低幼插画，采用极简主义的效率工具设计。

#### 📐 页面布局 (Layout Grid)
*   **左侧：** 考前复习时间流（Calendar & Timeline）。
*   **中间：** 番茄工作法钟（带启动、暂停、不确定性标注"？"按钮）。
*   **右侧：** 作业用时"预估 vs 实际"对照柱状图。

#### 🧩 核心组件与交互 (Components & Interaction)
1.  **"不确定题目标记"联动按钮：**
    *   当孩子在番茄钟计时器下写作业时，如果遇到难题，可点击屏幕上的 "我有疑问" 虚拟键，系统自动在错题本对应的科目下标注"？"并记录。
2.  **时间预测自适应引擎组件：**
    *   孩子输入"预估用时：30分钟"，完成后点击"我写完了"，系统记录"实际用时：45分钟"。
    *   系统用红色标出差异部分，弹出微交互引导："Leo，这道题比你预估的多花了15分钟，你觉得主要花在了哪个环节？（A. 读题耗时 B. 验算耗时 C. 发呆神游了）"。

### 8. 成长契约与勋章馆 (Family Covenant & Badge Room)

*   **设计目标：** 促成健康的亲子契约，将短期习惯打卡转化为长期的内在成就感。

#### 📐 页面布局 (Layout Grid)
*   **左侧 (契约签署区)：** 拟物化"家庭电子契约书"，有家长和孩子的手写签名展示。
*   **右侧 (勋章展览馆)：** 蜂巢状排布的勋章陈列架。已解锁的呈亮彩色，未解锁的呈暗灰色半透明。

#### 🧩 核心组件与交互 (Components & Interaction)
1.  **成长契约生成器交互：**
    *   家长端与孩子端共同在线选择奖励条件和奖励内容，自动生成一张"家庭法案"。
    *   **【UX 心理学防贿赂埋点】：** 当家长试图输入"给 100 元现金"作为奖励时，输入框下方弹出温和提示："循证医学表明，过度的物质奖励会削弱孩子的内在驱动力，建议选择'免家务一天'、'周五亲子电影夜'或'兑换1小时乐高组装时间'。"
2.  **勋章解锁动效：**
    *   解锁特定勋章时（如连续7天整理书桌解锁"镜面空间勋章"），全屏散落彩色纸屑，勋章卡片3D旋转放大，并伴随温和愉悦的轻音乐。
