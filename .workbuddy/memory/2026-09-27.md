## 修复 build-apk.bat 无法生成 APK 的问题

**根因**：脚本 `build-apk.bat` 只做 `where java` 存在性检查（不看版本），也从不设置 `JAVA_HOME`，
且 SDK 自动探测只认 `%LOCALAPPDATA%\Android\Sdk`。本机默认 `java` 是 JDK 8、SDK 在 `F:\androidSdk`，
导致：Gradle 8.14.3 用 JDK 8 跑必挂；`ANDROID_HOME` 为空时还会把 `local.properties` 写成空 `sdk.dir=`。

**已修复**（编辑 `build-apk.bat`）：
1. 新增 JDK 定位逻辑：优先 `D:\java\jdk-21\jdk-21.0.12.1+1` → Android Studio jbr → 系统 JAVA_HOME(17+)，并显式 `set JAVA_HOME`，用 JAVA_HOME 下的 java 报版本
2. SDK 探测新增 `F:\androidSdk` 与 `F:\Program Files\Android\Sdk`

修复后直接双击/运行 `build-apk.bat` 即可在本机跑通（无需手动设环境变量）。

**说明**：脚本内 `npx vite build --mode android` 不带 `--emptyOutDir=false`，在用户真机上正常（会清空 dist）；
该参数是当初在我的执行沙箱里绕过批量删除保护用的，不必写进脚本。
