## 安卓 APK 构建环境配置与首次打包

**背景**：用户询问本机能否把 Vue3 前端编译为安卓 APK。检查后发现环境不满足，逐项补齐并成功构建。

### 环境现状（已配置完成）
- **Android Studio**：`F:\Program Files\Android\Android Studio`（版本 Hedgehog AI-232，自带 jbr = JDK 17.0.9）
- **Android SDK**：`F:\androidSdk`
  - 原有：platforms 33/34、build-tools 30.0.3/34.0.0、platform-tools、licenses 已接受
  - 本次新增：platforms;android-36、build-tools;36.0.0
  - 注意：`F:\androidSdk\cmdline-tools` 不存在，只有旧版 `F:\androidSdk\tools\bin\sdkmanager.bat`
- **JDK 21**：`D:\java\jdk-21\jdk-21.0.12.1+1`（本次下载安装，Temurin 21.0.12.1）
- **系统原有 JDK**：`D:\java\jdk1.8.0_331`（JAVA_HOME 指向它，**不能用于本项目**）
- 本机无 Docker

### 关键结论
- 项目用 AGP 8.13.0 + Gradle 8.14.3 + compileSdk 36，**必须 JDK 17+**，JDK 8 直接失败
- 旧版 `sdkmanager.bat` 只能用 JDK 8 运行（JDK 11+ 缺 javax.xml.bind 会报 NoClassDefFoundError），且解压很慢（装 platform-36 约 10 分钟）

### 遇到的问题与修复
1. `@capacitor/*` 三个包未安装 → `npm install`（曾中断导致依赖不完整，`slice-ansi` 缺失，需重装）
2. `vite build` 失败：清空 dist 时触发执行环境的批量删除保护 → 用 `--emptyOutDir=false` 绕过；**不要**用 Python/shutil 删 dist（会被拦截）
3. `android/capacitor-cordova-android-plugins` 目录缺失 → 从 `node_modules/@capacitor/cli/assets/capacitor-cordova-android-plugins.tar.gz` 解压
   - **坑**：该 tar.gz 无顶层目录名，直接 extractall 到 `android/` 会覆盖根 `build.gradle` 并生成多余 `android/src`
   - 正确做法：先建 `android/capacitor-cordova-android-plugins/` 再解压进去
   - 已恢复根 build.gradle（AGP 8.13.0 + google-services 4.4.4 + apply variables.gradle）
4. 模板不含 `cordova.variables.gradle`，需手动建（空占位）
5. 模板 build.gradle 末尾引用 `cdvPluginPostBuildExtras` 未定义 → 在其 ext 块中加 `cdvPluginPostBuildExtras = []`

### 构建命令（可复用）
```bash
cd careless-correction
export JAVA_HOME="D:\\java\\jdk-21\\jdk-21.0.12.1+1"
export ANDROID_HOME="F:\\androidSdk"
npx vite build --mode android --emptyOutDir=false
npx cap copy android
cd android && ./gradlew.bat assembleDebug --no-daemon
```
- 首次构建 5 分多钟（含下载 Gradle 8.14.3 与依赖）
- 产物：`android/app/build/outputs/apk/debug/app-debug.apk`（12MB），已拷贝到项目根 `app-debug.apk`
- `android/local.properties` 已写入 `sdk.dir=F:\\androidSdk`
